## Создание базы данных для хранения результатов анкетирования

### Задание 1. - Создание таблиц для хранения бланка анкеты

Необходимо создать базу данных, которая:  
- сохранит форму анкеты, состоящей из вопросов и возможных ответов на них

1. Найдите в строке поиска `mySQLWorkbench` и запустите программу  
2. Добавьте новую модель `File \ New Model` и переименуйте ее с `myDB` на `AnketaDB-IS221`
3. Добавьте новую диаграмму через `Add diagram`
4. Добавьте новую таблицу (нажав на иконку с изображением таблицы)
```
Название: Anketa

Поля (Columns):
id INT PK NN AI
name VARCHAR(100)
created DATETIME

Это общее описание анкеты как сущности содержащей набор вопросов и возможных ответов в виде одной законченной формы или бланка
Пример:
101
'Анкета по профориентации для ИС-ов ККТ (весна 2024)'
'2024-04-24 10:00:00'
```
5. Создайте таблицу вопросов анкеты
```
Название: Question

Поля (Columns):
id INT PK NN AI
id_anketa INT
name VARCHAR(200)
shortname VARCHAR(50)

Это описание вопросов анкеты (id_anketa) как сущности содержащей описание конкретного вопроса
Пример:
2 (id)
101 (id_anketa)
'Определились ли вы с выбором будущей профессии?' (name)
'Определились с профессией' (short name)
```
6. Свяжите таблицу `Question` с таблицей `Anketa` созданием внешнего ключа 
```
Откройте вкладку `Foreign Keys`
добавьте новую запись (в левую таблицу) с Foreign Key Name = 'anketa_key' и Referenced Table = 'Anketa'
в правой таблице - отметьте галочкой поле `id_anketa` и в выпадающем списке `Referenced Column` выберите `id`
Поздравляем, вы построили связь `многие-к-одному` таблиц Question и Anketa
по полям Question.id_anketa и Anketa.id
```
7. Создайте таблицу возможных ответов на вопрос
```
Название: Answer

Поля (Columns):
id INT PK NN AI
id_question INT
name VARCHAR(100)

Это описание вариантов ответов на вопросы (id_question) анкеты как сущности содержащей описание конкретного варианта ответа

Пример:
1 (id)
2 (id_question)
'Да' (name)
```
