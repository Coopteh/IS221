### Занятие 1 (18-02-25) Статус услуг
описании задания указано, что Техник может:  
- Менять статус оказания услуг.

Давайте добавим статус, варианты этого поля:  
("прием", "в работе", "завершен", "отменен")

1. Создать поле в БД в таблице журнала с названием "status" VARCHAR(20) DEFAULT 'прием'
2. Добавим поле статус в Журнал:
```
- для этого изменим Models\ServiceDBStorage
во все методы, где есть sql-запросы (SELECT, INSERT, UPDATE) добавим еще одно поле status
```
3. Изменим таблицу на просмотр - представление
в методе Views\Templates\ServiceTemplate::getServiceTemplate()
```
В таблицу добавить заголовок 'Статус'
и столбец с $row['status']
```
4. Изменим форму для вставки-изменения записи
представление в методе Views\Templates\ServiceTemplate::getFormTemplate()
```
можете скопировать код выбора клиента (select)
вместо foreach добавьте option c value "прием", "в работе", "завершен", "отменен"
```
5. изменить в роутере Routers маршруты 'add_record' и 'edit_record', чтобы
в массив $row попадало поле status из массива $_POST
