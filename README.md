### Задание 4. Выборка со связью 2 таблиц

Чтобы связать две таблицы используют оператор JOIN (LEFT JOIN)
```
SELECT column_name(s)
FROM table1
LEFT JOIN table2
ON table1.column_name = table2.column_name;
```
в нашем случае
```
SELECT s.name, g.subject, g.grade
FROM students s
LEFT JOIN grades g
ON s.id = g.student_id
```
