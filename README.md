## Учебная и производственная практики по  
## ПМ.06 СОПРОВОЖДЕНИЕ ИНФОРМАЦИОННЫХ СИСТЕМ 

## Индивидуальное задание 

Индивидуальное задание заключается в изучении и использовании методов  
и средств инженерно-технической поддержки сопровождения информационной системы:  
- Настройке доступа к сетевым устройствам
- Настройке политики безопасности
- Создании резервной копии информационной системы
- Создании резервной копии базы данных
- Восстановлении данных
- Восстановлении информационной системы
- Сборе информации об ошибках. Формирование отчетов об ошибках
- Выполнение обслуживания информационной системы в соответствии с пользовательской документацией
- Обслуживание локальной сети  
- Документирование процессов внедрения и сопровождения информационных систем  
- Разработка сценария внедрения информационной системы для рабочего места  
- Разработка технического задания на внедрение информационной системы  
- Разработка графика разработки и внедрения информационной системы  
- Разработка перечня обучающей документации на информационную систему  
- Разработка технического задания на сопровождение информационной системы
- Формирование предложений о расширении информационной системы
