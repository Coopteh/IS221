## Содержание диплома (детально)  

### Введение  
Актуальность (онлайн торговли для компании из вашей отрасли)  
Цель - основная из темы  
Задачи - перечень соответствует подразделам основной части (содержанию)  
Объект - процесс онлайн продаж, интернет торговли из отрасли по теме  
Предмет - динамический веб-сайт (взять из темы)    

### Основная часть  

1. Теоретические сведения о развитии информационной системы предприятия  

1.1 Существующие подходы к проектированию информационных систем  
Жизненный цикл ПО, модели разработки (каскадная, итеративные).  
Выбранная модель разработки - итеративная - https://prepodis.ru/articles/zhiznennyj-tsikl-razrabotki-po
Выбор и характиристики IDE - Visual Studio Code (сравнение с другими, преимущества)
использование фреймворка Bootstrap для интерфейсной, клиентской части, его преимущества (адаптивный дизайн сайта)  
Используемый язык для серверной части - PHP (сравнение с другими, преимущества)  
Архитектура проекта - клиент-серверная модель (что это, описать).  
Выбранная СУБД - mySQL (сравнение с другими, преимущества)

1.2 Особенности проектирования информационной системы для предприятий розничной торговли  
важность, наличие онлайн-представления в интернет пространстве, возможность выбора товара в корзину, карточки товаров, карусель популярный товаров на главной странице  

2 Анализ деятельности предприятия   

2.1 Организационная характеристика предприятия  
типичная организация предприятия розничной торговли из вашей сферы (отрасли)  

2.2 Анализ состояния информационной системы компании  
важность наличие онлайн-представления в интернет пространстве, возможность продажи товаров онлайн  
SWOT-анализ (конкурентов) и PEST-анализ рынка, целевая аудитория  
Краткий вывод по главе о целесообразности разработки ... поскольку анализ показал высокий потенциал и рост ...   

3 Разработка функциональных элементов интернет-магазина   

3.1 Определение функций интернет-магазина   
Составление анкеты с вопросами для заказчика (брифа)  
Ответы заказчика на эти вопросы.  
Анализ ответов и составление технического задания по брифу с ответами заказчика

## Cтруктура ТЗ  
включает следующие разделы:  

1) Введение:  
o Цель проекта (что вы хотите достичь).  
o Общая концепция сайта.  

2) Требования:  
o (2.1) Функциональные:  
Формулируются глаголами: "система должна предоставлять", "должна обеспечивать"  
Должны быть конкретными и проверяемыми  
Пример:  
"1.2. Система должна предоставлять возможность:  
- Выбора пиццы из каталога  
- Индивидуального составления пиццы  
- Оформления заказа в 3 шага  

o (2.2) Нефункциональные:    
- Производительность (время отклика, нагрузка)  
- Безопасность (защита данных, авторизация)  
- Надежность (время безотказной работы, нагрузка, восстановление)  
- Юзабилити (удобство интерфейса)  
Пример:  
"3.1. Время загрузки страниц не должно превышать 2 секунд при скорости интернета 10 Мбит/с"  

3) Ограничения:  
Что включать:  
- Технологические ограничения, Бюджетные рамки, Ресурсные ограничения
