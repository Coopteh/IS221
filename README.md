### Индивидуальное задание на УП, ПП 03.01 "Ревьюирование программных модулей"  
Цель задания:  
Научиться осуществлять ревьюирование программного кода, анализировать его характеристики, выявлять ошибки и проводить сравнительный анализ программных продуктов с использованием специализированных инструментов.   

Задания:   
Изучение технической документации: ознакомьтесь с техническим заданием (ТЗ) на разработку программного модуля. Определите ключевые требования и спецификации.  
Ревьюирование кода: проведите ревью предоставленного программного кода (объемом не менее 200 строк). Оцените его соответствие требованиям ТЗ. Зафиксируйте выявленные недостатки и предложения по улучшению.  
Измерение характеристик: используя инструменты статического анализа, измерьте характеристики кода: производительность, сложность и количество ошибок. Оформите результаты в виде отчета.  
Исследование алгоритмов: выберите один из алгоритмов, реализованных в коде, и проанализируйте его корректность. Проведите тестирование алгоритма с использованием юнит-тестов. Зафиксируйте результаты тестирования.  
Сравнительный анализ: проведите сравнительный анализ двух аналогичных программных продуктов или средств разработки (фреймворков). Оцените их по критериям: производительность, удобство использования, поддержка сообщества и стоимость.  
Ожидаемые результаты: подготовьте итоговый отчет, в который включите результаты ревьюирования кода, измеренные характеристики, анализ алгоритма и результаты тестирования, сравнительный анализ программных продуктов, рекомендации по улучшению качества кода и выбору инструментов разработки.  

Все результаты работы должны быть оформлены в виде отчета, который будет представлен на защите производственной практики.
