## Создание базы данных для хранения результатов анкетирования

### Задание 1. - Создание таблиц для хранения формы опроса

Необходимо создать базу данных, которая:  
- сохранит форму анкеты, состоящей из вопросов и возможных ответов на них

1. Найдите в строке поиска `mySQLWorkbench` и запустите программу  
2. Добавьте новую модель `File \ New Model` и переименуйте ее с `myDB` на `AnketaDB-IS221`
3. Добавьте новую диаграмму через `Add diagram`
4. Добавьте новую таблицу (Опросы), нажав на иконку с изображением таблицы
```
Название: Polls 

Поля (Columns):
p_id INT PK NN AI
name VARCHAR(100)
created DATETIME

Это общее описание анкеты как сущности содержащей набор вопросов и возможных ответов
в виде одной законченной формы или бланка для анкетирования

Пример:
101
'Опрос по профориентации для ИС-ов ККТ (весна 2024)'
'2024-04-24 10:00:00'
```
5. Создайте таблицу вопросов анкеты
```
Название: Questions

Поля (Columns):
q_id INT PK NN AI
p_id INT
name VARCHAR(200)
short_name VARCHAR(50)

Это описание вопросов анкеты (id_anketa) как сущности содержащей описание конкретного вопроса
Пример:
2 (q_id)
101 (p_id)
'Определились ли вы с выбором будущей профессии?' (name)
'Определились с профессией' (short_name)
```
6. Свяжите таблицу `Questions` с таблицей `Pools` созданием внешнего ключа 
```
Откройте вкладку `Foreign Keys`
добавьте новую запись (в левую таблицу) с Foreign Key Name = 'pool_key' и Referenced Table = 'Polls'
в правой таблице - отметьте галочкой поле `p_id` и в выпадающем списке `Referenced Column` выберите `p_id`
Поздравляем, вы построили связь `многие-к-одному` таблиц Questions и Polls
по полям Questions.p_id и Pools.p_id
```
7. Создайте таблицу вариантов ответов на вопрос (Options)
```
Название: Options

Поля (Columns):
o_id INT PK NN AI
q_id INT
name VARCHAR(100)

Это описание вариантов ответов на вопросы (q_id) анкеты
как сущности содержащей описание конкретного варианта ответа

Пример:
1 (o_id)
2 (q_id)
'Да' (name)
```
6. Свяжите таблицу `Options` с таблицей `Questions`
созданием внешнего ключа `question_key` по полям Options.q_id и Questions.q_id

7. Создайте таблицу (реальных) ответов на вопрос (Answers)  
```
Название: Answers

Поля (Columns):
a_id INT PK NN AI
q_id INT
n_student INT
name VARCHAR(100)

Это описание вариантов ответов на вопросы (q_id) анкеты как сущности содержащей описание конкретного варианта ответа
одного студента (n_student)

Пример:
1 (a_id)
2 (q_id)
1 (n_student)
'Да' (name)
```
6. Свяжите таблицу `Answers` с таблицей `Questions`
созданием внешнего ключа `question_key` по полям Answers.q_id и Questions.q_id

### Задание 2. - Экспорт скрипта на создание и Создание БД

1. Выполните для загруженной модели File \ Export \ Forward Engeneer SQL CREATE Script
(указав название скрипта `Anketa-IS221`, два раза нажмите Next и один раз Finish)
(если ругается на права - скопируйте через буфер обмена и создайте файл через `Блокнот`, называем файл `Anketa-IS221.sql`)
2. Запустите сервер СУБД mySQL через программу `XAMPP Control Panel` (найдите в строке поиска)
- нажмите кнопку Start, чтобы надпись mySQL загорелась зеленым
3. Закройте mySQLWorkbench и запустите программу заново
4. Нажмите `mySQL Connection` кнопку (+) для создания нового соединения (назовите его IS221-connection и нажмите OK)  
Нажмите на получившееся соединение (откроется окно с молниями)
5. Откройте скрипт на создание базы данных (БД) через меню `File \ Open script`  
(Удалите VISIBLE для всех таблиц - может мешать при выполнении скрипта)  
и запустите загруженный скрипт на выполнение нажатием молнии.  
Если ошибок не случилось - поздаравляю, Вы создали БД
- откройте вкладку Schemas (в левой панели) и, вызвав правой клавишей мыши контекстное меню, обновите схему данных, выбрав пункт Refresh All
- если НЕ ПОЛУЧИЛОСЬ - загрузите файл [Anketa-IS221.sql](Anketa-IS221.sql) и скопируйте его содержимое для выполнения - это рабочий вариант, должен сработать
