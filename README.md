### Индивидуальное задание на учебную практику

1. Создание концептуальной модели данных.  
Изучение предметной области и требований к базе данных. Разработка концептуальной модели, описывающей основные сущности и их взаимосвязи)  
2. Использование нотации ER (сущность-связь) для визуализации модели.  
Изучение создания логической модели данных. Перевод концептуальной модели в логическую, с учетом реляционной модели данных.   
3. Определение основных атрибутов и связей, нормализация.  
Определение атрибутов сущностей, установление первичных и внешних ключей. Нормализация данных для устранения избыточности.  
4.  Создание физической модели данных  
Проектирование таблиц базы данных на основе логической модели. Определение типов данных для каждого атрибута и настройка индексов. Подготовка скриптов для создания объектов базы данных в выбранной СУБД.  
5. Разработка ER-модели  
Создание ER-диаграммы, отражающей сущности, атрибуты и связи между ними. Использование специализированного ПО для моделирования баз данных (MySQL Workbench).  
6. Настройка сетевого адаптера и межсетевого взаимодействия  
Изучение основ настройки сетевых адаптеров для подключения к базе данных. Настройка межсетевого взаимодействия с использованием протоколов TCP/IP.  
Проведение тестирования соединения с базой данных.  
7. Выполнение запросов на языке SQL  
Изучение основ SQL: SELECT, INSERT, UPDATE, DELETE. Выполнение простых и сложных запросов к базе данных, оптимизация выполнения запросов.  
8. Разработка политики безопасности для SQL сервера  
Определение уровней доступа пользователей к базе данных. Настройка ролей и прав доступа в MySQL SQL Server. Разработка рекомендаций по защите данных от несанкционированного доступа.  
9. Мониторинг нагрузки сервера   
Изучение инструментов мониторинга производительности SQL сервера. Анализ нагрузки на сервер: использование ресурсов, время выполнения запросов.  
Оптимизация запросов и индексов на основе полученных данных.  

### Индивидуальное задание на производственную практику

1. Создание концептуальной модели данных: изучение предметной области.  
Определение основных сущностей и их взаимосвязей; разработка ER-модели.  
Проектирование логической модели данных: перевод концептуальной модели в логическую.  
Определение атрибутов, первичных и внешних ключей.  
Нормализация данных до третьей нормальной формы.  
Создание физической модели данных: проектирование таблиц базы данных; определение типов данных для атрибутов.  
Настройка индексов для оптимизации запросов.  
2. Разработка объектов базы данных  
Выполнение запросов на языке SQL: выполнение запросов на просмотр, вставку, изменение и удаление данных.  
Составление и выполнение сложных запросов с использованием JOIN и подзапросов.  
Создание представлений, хранимых процедур, триггеров.  
3. Настройка серверов баз данных  
Настройка сетевого адаптера: настройка сетевых адаптеров; настройка параметров TCP/IP для подключения к базе данных; тестирование соединения.  
Настройка межсетевого взаимодействия: конфигурация межсетевых экранов и маршрутизаторов. Обеспечение безопасного доступа к базе данных через сеть.  
Тестирование межсетевого взаимодействия.  
4. Обеспечение защиты данных  
Разработка политики безопасности для SQL сервера: определение уровней доступа пользователей к базе данных.  
Настройка ролей и прав доступа в MySQL SQL Server; разработка рекомендаций по защите данных от несанкционированного доступа.  
5. Мониторинг производительности серверов баз данных  
Мониторинг нагрузки сервера: изучение инструментов мониторинга производительности SQL сервера.   
Анализ нагрузки на сервер: использование ресурсов, время выполнения запросов.   
Оптимизация запросов и индексов на основе полученных данных.
