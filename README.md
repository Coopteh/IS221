## Создание базы данных оценок студентов по предметам

*Цели занятия:*  
1. Познакомиться с новым инструмерном проектирования и работы с БД - `phpMyAdmin`
2. Необходимо создать базу данных `Grade-IS221`, 
которая содержит две таблицы `Students` (инфа о студентах) и `Grades` (инфа о их оценках)    
двумя способами:
- с помощью визуальных средств проектирования (в phpMyAdmin)
- с помощью языки запросов SQL, конструкции вида
```
Запрос на создание
CREATE TABLE <название таблицы> (
    id INT AUTO_INCREMENT,
    name VARCHAR(50),
    ...
    PRIMARY KEY('id')
);

Запрос на вставку
INSERT INTO <название таблицы> (id, ...) VALUES
(1, 'Иван', .. ),
(2, 'Мария', ...);
```

### Задание 1. - Создание БД

Учебное видео 
1. Запустите сервер СУБД `mySQL` и веб-сервер `Apache` через `XAMPP Control panel` - нажмите кнопку start для mySql, Apache
2. Запустите `phpMyAdmin` - нажав кнопку `admin` напротив `mySQL`
3. Создайте базу данных `Grade-IS221`, затем таблицу `students` с 4 столбцами  
7. Запишите их
```
Таблица "студенты":
- id (идентификатор студента) - id INT (A_I + PRIMARY)
- имя (имя студента) - name VARCHAR(50)
- возраст (возраст студента) - age INT
- курс (курс, на котором учится студент) - course INT
```
6. Вторую таблицу `grades` создайте с помощью запроса - вкладка `SQL`
```
Шаблон запроса на создание
CREATE TABLE <название таблицы> (
    id INT AUTO_INCREMENT,
    ...
    PRIMARY KEY('id')
);

Таблица "оценки" grades:
- id (идентификатор оценки) - id INT
- student_id (идентификатор студента) - student_id INT
- предмет (название предмета) - subject VARCHAR(50)
- оценка (оценка по предмету) - grade INT
```
