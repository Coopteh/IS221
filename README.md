## Преддипломная практика для ИС-221  

Период практики: c 20.04.2026 по 17.05.2026  
Срок сдачи отчета: 16.05.2026 (суббота)  
Задание - написать ТЗ, разработать сайт с тестами для предприятия практики  
оформить в отчет и сделать скриншоты  

### Индивидуальное задание на практику
```
1. Анализ технического оснащения предприятия компьютерной техникой:
ознакомление с должностными инструкциями вычислительного центра или соответствующих отделов,
проведение анализа структуры вычислительного центра/отдела, анализ технических возможностей
компьютерной техники в подразделении;
ознакомление с типами и конфигурацией компьютеров и оргтехники, задействованных на предприятии,
анализ архитектуры сети на предприятии, если она есть.

2. Анализ программного обеспечения предприятия: ознакомление с существующими системами защиты данных;
ознакомление с операционной системой, установленной на предприятии;
проведение анализа возможности работы операционной системы для реализации дипломного проекта.

3. Обоснование выбора задачи для автоматизации:
анализ исходных данных и способов автоматизации работы предприятия в рамках темы своего дипломного проекта.

4. Постановка профессиональной задачи: исследование предметной области в рамках темы и задач дипломного проекта;
выделение информационных объектов, необходимых для решения профессиональной задачи.

5. Технология решения поставленной профессиональной задачи: проанализировать этапы решения задачи.

6. Ознакомление с требованиями заказчика: проведение встречи с заказчиком для обсуждения проекта;
сбор и анализ требований к программному продукту.

7. Проектирование архитектуры программного продукта:
разработка архитектуры приложения; определение технологий и инструментов разработки.

8. Создание прототипа пользовательского интерфейса:
разработка макетов интерфейса; обсуждение и утверждение прототипа с заказчиком.

9. Разработка основной функциональности: написание кода для ключевых функций приложения;
написание кода для интеграции с базой данных.

10. Тестирование разработанного функционала:
проведение юнит-тестирования разработанных классов;
отладка и исправление выявленных ошибок.

11. Оптимизация производительности приложения:
анализ производительности; внедрение улучшений для повышения скорости работы.

12. Финальное тестирование и отладка:
проведение интеграционного тестирования; исправление оставшихся ошибок и доработка функционала.

13. Разработка пользовательской документации:
создание руководства пользователя, включая описание интерфейса и основных функций;
подготовка инструкций по установке и настройке программного продукта.

14. Создание технической документации:
разработка технического описания системы, включая архитектуру и используемые технологии;
описание алгоритмов и структур данных, применяемых в продукте;
подготовка раздела по тестированию; описание методов тестирования программного продукта;
включение результатов тестирования и известных проблем.

15. Разработка раздела по поддержке и обслуживанию:
подготовка инструкций по обновлению и сопровождению программного продукта;
описание процессов обращения в службу поддержки.

16. Редактирование и форматирование документации:
проверка на наличие ошибок и несоответствий;
форматирование документов в соответствии с установленными стандартами.
```  
### Пакет документов  

Пакет документов должен включать 1 отчет:  
1. Отчет по преддипломной практике + Индивидуальное задание + Дневник прохождения  + Характеристика с предприятия + Аттестационный лист
Печати ставить где указано место печати (М.П. - в Характеристике и Аттестационном листе)  
В индивидуальном задании нужна ваша подпись и подпись руководителя от предприятия   

Для вашего удобства и правильности заполнения - подготовлен полный **заполненный комплект документов**

Скачайте его и заполните свое ФИО, Место прохождения практики, подготовьте содержательную часть в виде отчета по практике.
