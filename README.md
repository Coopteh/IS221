### Образец практического задания

```
Откройте приложение `XAMPP Control panel`.
Запустите в нем сервер СУБД `mySQL` и веб-сервер `Apache`.
Откройте веб-приложение phpMyAdmin для управления базами данных.

1. Создайте базу данных `exam`,
в отдельной вкладке, напишите скрипт создания таблицы `persons`
с 4 столбцами (id - тип целое, name - тип строка в 120 символов,
age - тип целое, gender - тип 1 символ)
Для поля id установите первичный ключ и автоинкрементацию.

2. В отдельной вкладке, напишите скрипт, который добавляет
в таблицу `persons` следующий набор строк:
(1, 'Дмитрий', 16, 'м'), (2, 'Семен', 16, 'м'), (3, 'Алена', 16, 'ж'),
(4, 'Федор', 31, 'м'), (5, 'Маруся', 46, 'ж'), (6, 'Дмитрий', 26, 'м'),
(7, 'Иван', 36, 'м'), (8, 'Наталья', 22, 'ж')

3. В отдельной вкладке, напишите скрипт, который группирует
таблицу `persons` по полу - поле gender
и вычисляет средний возраст (поле age) в каждой из групп.

Ответ: (ж, 28) и (м, 25)
```
