### Основные термины и определения к дисциплине "Основы проектирования баз данных"

```
База данных - организованный набор взаимосвязанных данных, хранящихся в компьютерной системе.

Основные компоненты системы управления базами данных (СУБД):
Язык описания данных (DDL), язык манипулирования данными (DML), оптимизатор запросов, механизм управления транзакциями.

Связь "один-к-одному" (1:1) - это когда каждому экземпляру сущности А соответствует один и только один экземпляр сущности Б и наоборот.
Пример: сущность Студент и сущность Паспорт

Основные модели данных: реляционная, иерархическая, сетевая

Связь "один-ко-многим" (1:М) - такой тип связи, когда каждому экземпляру сущности А может соответствовать ни одного, один или несколько экземпляров сущности Б,
однако каждому экземпляру сущности Б соответствует один и только один экземпляр сущности А.
Пример: мать - дети

Реляционная модель данных - модель, в которой данные представлены в таблицах, каждая из которых содержит строки (записи) и столбцы (поля).

Связь "многие-ко-многим" (M:N) - такой тип связи, при котором каждому экземпляру сущности А может соответствовать ни одного, один или несколько экземпляров сущности Б, и наоборот.
Пример: студенты - преподаватели

Первичный ключ - уникальный идентификатор, который отличает каждую строку в таблице.

Внешний ключ - поле (или поля), которое связывает строки в разных таблицах.

Нормализация - процесс разделения таблиц на меньшие таблицы для удаления дублирования данных и улучшения целостности данных.

Типы нормлизации: первая нормальная форма (1NF), вторая нормальная форма (2NF), третья нормальная форма (3NF)

Декомпозиция базы данных - процесс разделения схемы базы данных на меньшие части, которые могут быть соединены для создания исходной схемы.

Целостность данных - гарантия того, что данные в базе данных являются точными, согласованными и действительными.

Индексы - структуры данных, которые ускоряют поиск данных в базе данных.

NULL - означает отсутствие значения
 
Запрос - команда для извлечения данных из базы данных.

Основные операторы (команды) SQL: SELECT, INSERT, UPDATE, DELETE.

Объединение - операция, которая объединяет данные из нескольких таблиц. Ключевое слово UNION

Типы объединений: внутреннее объединение, внешнее объединение, самообъединение.

Реляционная алгебра - множество операций, которые можно использовать для манипулирования отношениями (таблицами).

Язык манипуляции данными (DML) - подмножество SQL, используемое для создания, обновления и удаления данных.

Язык описания данных (DDL) - подмножество SQL, используемое для определения структуры базы данных, такой как таблицы и индексы.

Преимущества которые обеспечивает СУБД:
1) восстановление после сбоев
2) высокая производительность работы с данными
3) многопользовательский доступ
4) резервное копирование

Сущность (в ER модели) - это абстракция какого-либо объекта, процесса или явления реального мира, о котором нужно хранить информацию.

Типы связей между таблицами в базе данных: один-ко-многим, многие-ко-многим, один-к-одному

Преобразование модели ER в реляционную модель - процесс перевода концептуальной модели ER в логическую реляционную модель.

ER-модель (от англ. Entity-Relationship model, модель «сущность — связь») — модель данных, позволяющая описывать концептуальные схемы предметной области. 

Шаги преобразования модели ER в реляционную модель: идентификация сущностей, атрибутов, связей, первичных и внешних ключей, нормализация.

Атрибут (сущности в ER-модели) - это поименованная характеристика сущности, которая принимает значение из некоторого множества значений.

Обязательность (атрибута в ER-модели) означает, что атрибут не может принимать неопределенных значений (NULL значение)

Оптимизация базы данных - процесс улучшения производительности базы данных за счет настройки ее физических и логических характеристик (индексация данных, изменение размера кеша и т.д.)

Репликация данных - создание и поддержание копий данных в нескольких местах (например в разных регионах).

Суррогатный ключ - это внутренний номер для нумерации экземпляров сущности (записей таблицы), не имеющий смысла вне системы (БД). После создания идентификатора записи создается первичный ключ на его основе - он суррогатный

Связь (в ER-модели) - поименованная ассоциация между двумя сущностями.
```
