# Задача 1. "Угадай число"

Создать простую игру "Угадай число" на python.  
Это задание позволит познакомиться с базовыми концепциями программирования и развлечь посетителей,  
школьников и их родителей, в "День открытых дверей".  

Выполните по шагам:
```
// TODO - консольная игра "Угадай число"
- импортируйте библиотеку random
- задайте переменной secret число от 1 до 100, вызовом функции из этой библиотеки random.randint(1, 100)
- выведите на экран консоли строку "Я загадал число от 1 до 100.")
- присвойте переменной i значение 0 - это будет счетчик числа попыток угадать ответ
- задайте бесконечный цикл while
- в теле цикла:
  - присвойте переменной answer ввод с консоли по запросу "Попробуй угадать число:" (функция input)
  - присвойте переменной n приведение переменной строкового типа answer к типу int (функция int)
  - увеличьте счетчик числа попыток i на 1
  - проверьте условия - если введенное число < заданого (secret), тогда вывести "Загаданное число больше."
  - иначе проверьте условие - если введенное число > заданого (secret), тогда вывести "Загаданное число меньше."
  - иначе - вывести шаблонную строку f"Поздравляю! Ты угадал число {secret} за {i} попыток."
  - прервите выполнение цикла
- выведите сообщение "Спасибо за игру! До новых встреч!"
```
Проверьте за какое число попыток вы угадаете число.
