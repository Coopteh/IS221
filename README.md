### Индивидуальное задание на УП, ПП 05.01 "Проектирование и разработка информационных систем"  

Цель задания:  
Приобретение практического опыта в проектировании и разработке информационных систем, развитие профессиональных компетенций и навыков, необходимых для успешного выполнения задач в данной области.  

Задания:  
1. Сбор исходных данных для проектной документации: проведите анализ предметной области, соберите и систематизируйте данные, необходимые для проектирования информационной системы; подготовьте отчет о проведенных интервью с пользователями и выявленных требованиях.  
2. Формулирование требований к информационной системе: разработайте функциональные и нефункциональные требования к проектируемой системе; составьте описание сценариев использования системы (use-case).  
3. Разработка проектной документации: создайте техническое задание (ТЗ) на разработку информационной системы на основе собранных данных; оформите проектную документацию в соответствии с установленными стандартами.  
4. Проектирование архитектуры информационной системы: определите архитектурный подход для проектируемой системы (клиент-серверная, микросервисная и т.д.); разработайте схемы и диаграммы, описывающие архитектуру системы.  
5. Разработка подсистем безопасности: проведите анализ угроз безопасности для проектируемой системы; разработайте меры защиты данных и проектируйте подсистему аутентификации и авторизации.  
6. Программирование модулей информационной системы: реализуйте один из модулей системы согласно техническому заданию; используйте соответствующий язык программирования и инструменты разработки.  
7. Тестирование информационной системы: проведите функциональное тестирование разработанного модуля; документируйте результаты тестирования и выявленные ошибки.  
8. Разработка технической документации на эксплуатацию: создайте инструкции по эксплуатации и обслуживанию системы для пользователей; подготовьте документацию для администраторов системы.  
9. Оценка качества функционирования информационной системы: проведите анализ производительности разработанной информационной системы; составьте отчет о качестве работы системы с рекомендациями по улучшению.  
10. Модернизация информационной системы: на основе анализа текущего состояния ИС предложите план модернизации, включая обновление функционала или технологий.  

Ожидаемые результаты: подготовленный отчет о выполненных заданиях с описанием процесса работы; документация, включающая техническое задание, инструкции для пользователей и отчеты о тестировании; практические навыки в проектировании и разработке информационных систем.  
Все результаты работы должны быть оформлены в виде отчета, который будет представлен на защите производственной практики.
