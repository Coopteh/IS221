### Образец практического задания

```
1. Создайте класс "Deposit" на Python с полем "sum" (сумма депозита)
и методом "profitFiveMonth()", который вычисляет прибыль от депозита в 12% годовых
по прошествии 5 месяцев (sum * 0.12 * 5 / 12).

2. Создайте модульный тест, проверяющий результат работы метода profitFiveMonth()
класса Deposit на двух примерах:
 1000* 0.12 * 5 / 12 = 50
 5000* 0.12 * 5 / 12 = 250
```
